# ERP UX Pass

This release standardizes the main ERP interaction patterns.

- Shared modal behavior with Escape and outside-click close.
- Explicit Cancel actions in modal workflows.
- Searchable selects for longer option lists.
- Shared page headers, empty states, status badges, and button variants.
- Purchase Requisition creation moved into a focused modal.
- Purchase Order creation moved into a focused modal with searchable PR selection.
- Purchase Order receipt moved into a focused modal.
- Item Master and Warehouse creation use the shared modal pattern.
- Audit Log filters use the shared searchable select.
- PR, PO, Item Master, Warehouse, and Audit Log pages use clearer empty/loading/error states.
